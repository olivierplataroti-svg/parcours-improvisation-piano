Comment lire ces chiffres ?

Une séance compte uniquement lorsqu'elle est marquée comme terminée. Pour Vocabulaire, les minutes au piano et hors piano restent distinctes. Les durées affichées sont celles inscrites dans tes applications (durée des séances Blues/Jazz et durée réelle renseignée dans Bases et Écoute intérieure). Les moyennes représentent du temps enregistré, pas un suivi automatique du clavier ou de la concentration.

Synchronisation depuis les icônes iPad

Touche ☁ Connecter mon suivi en bas à droite et utilise le même accès Piano que dans tes cinq applications. Ouvre chaque icône une première fois pour transmettre son historique. Ensuite, le tableau de bord récupère les mises à jour à son ouverture, à ton retour et toutes les 30 secondes lorsqu’il est visible.

Import manuel facultatif

  1. Depuis chaque parcours, exporte sa sauvegarde JSON dans Fichiers (sur iPad, iCloud Drive ou Google Drive).
  2. Dans ce tableau de bord, touche Choisir les fichiers JSON et sélectionne les sauvegardes des cinq parcours. Tu peux aussi n'importer que celui qui a changé.
  3. Les statistiques sont recalculées immédiatement. Une fois importées, elles restent disponibles dans ce navigateur.

Si tu stockes les fichiers dans un dossier Google Drive, l'application Fichiers peut les présenter comme des documents locaux. Le choix du fichier reste une action manuelle.

Lecture automatique des sites GitHub

Si cette page et tes applications Blues/Jazz/Écoute intérieure sont ouvertes dans Safari sous le même domaine github.io, le tableau de bord peut lire leurs sauvegardes directement dans le stockage local, sans fichier à sélectionner.

Les applications installées séparément sur l’écran d’accueil ont des stockages isolés : utilise la synchronisation privée pour les relier. La lecture locale reste disponible pour les onglets Safari partageant le même stockage. Les sites OpenAI d’origine nécessitent un import séparé.

Exporter et conserver ton historique

Un export global permet de préserver les quatre sauvegardes, ton répertoire classique et tes réglages du tableau de bord. Le CSV est un relevé de statistiques, sans notes de séance.

Attention : le stockage local de Safari peut être vidé si tu effaces les données du site. Continue de sauvegarder régulièrement tes parcours.
